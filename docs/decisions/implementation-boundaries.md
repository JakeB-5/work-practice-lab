# 구현에서 확정한 계약

- 정본 API·도메인 계약은 `packages/contracts/`다. `docs/specification/`은 개발 착수 시점의 명세 사본이다. 변경된 DTO는 통합 테스트가 정본 스키마로 검사한다.
- 브라우저의 첫 HTML에 60초 일회성 시작 토큰을 주입하고 HttpOnly 쿠키 및 CSRF 토큰으로 교환한다. 유효한 기존 세션은 재사용한다. 제어 호스트는 `127.0.0.1`, 과제 미리보기는 `localhost`의 별도 포트다.
- 로컬 추론은 한 슬롯이다. 동시 실행 설정은 1로 고정하며 큐 순서·취소를 제공한다.
- terminal 생성은 Process를 반환한다. 일회성 티켓은 별도 API에서 발급한다. 프로세스 중단은 실제 종료 확인 후 Process를 반환한다. 삭제와 실패 주입은 동기 확인 JSON을 반환한다.
- Operation에는 결과 객체, Evaluation에는 입력 근거 coverage와 executionMode를 추가했다. 사용자 질문용 승인 DTO와 사후 답변 locator도 추가했다. 확정 사후 답변은 사용자 출처 근거로 수집한다.
- 기본 호스트 AGENTS·스킬·앱·플러그인·MCP 상속은 제한한다. `project_doc_max_bytes=0`을 사용해 호스트 문서를 재귀 탐색하지 않는다. 코딩은 정규화된 실제 Codex 바이너리와 명명된 파일 권한 프로필을 사용한다.
- 담당자·평가자 등 제한 역할에 실행 환경을 주지 않는다. 메타데이터용 도구가 전혀 없다는 주장은 하지 않는다. 실제 파일 접근 경계와 역할별 요청 결과를 증거로 남긴다.
- 자동 검증은 첫 화면 관찰, 지원되는 과제 API 흐름, 사용자 수정 검사를 구분한다. 지원 인터페이스가 없으면 미실행으로 기록하며 화면이 열린 것만으로 전체 과제를 통과시키지 않는다.
- 재생 모드는 모델 평가가 아니다. 리포트와 내보내기에도 replay 모델과 미평가 이유를 표시한다.
