# 과제 제작·버전 저장

과제 상세의 제작 버튼을 누르면 공개 자료와 비공개 담당자·평가·검증 자료를 별도 영역에 편집한다. 이 열람은 활성 시도에 `private_material_exposed`로 기록하며, 활성 시험 연습에서는 서버가 거절한다.

공개 자료의 경로는 `public/resources/<id>.md`로 서버가 생성한다. 임의 경로를 입력받지 않는다. 비공개 JSON은 고정된 private 경로에만 기록한다. 비공개 내용을 공개 편집 칸으로 자동 복사하지 않는다. 사용자가 공개 문서에 직접 적은 내용까지 비밀로 추론해 삭제하지 않는다.

검사·미리보기는 임시 복사본에서 ID·버전·경로·자료 중복·사실 참조·평가 축·명령 제한을 검사한다. 새 버전 저장은 전체 파일의 정렬된 SHA-256 목록으로 패키지 digest를 고정한다. 같은 버전의 다른 내용은 거절한다. 기존 시도는 기존 scenarioVersionId와 소유 복사본을 계속 참조한다.

`GET /authoring/:id`, `POST /authoring/:id/preview`, `POST /authoring/:id`. 로컬 인증·CSRF 적용. 공개 미리보기는 제목·설명·자료 목록만 반환한다. 저장 전 공개 문서 본문은 편집 영역에서 확인한다.
