# 사용자 스킬·도구 연결

사용자가 직접 선택한 Markdown 텍스트와 JSON 도구 정의만 가져온다. 호스트 전체 설정이나 연결된 서비스의 인증값을 자동 수집하지 않는다. 등록 시 SHA-256을 표시하고 기본 비활성 상태로 저장한다. 검토한 동일 hash의 활성화 요청만 허용한다.

스킬 텍스트는 코딩 도우미의 사용자 맥락으로 제공한다. 담당자·평가자·과제 앱에는 제공하지 않는다. 도구 JSON은 `name`, `description`, `command` 문자열 배열, `inputSchema`를 포함한다. 실행 시 검증된 인자를 JSON 문자열인 마지막 argv로 넘긴다. `${WORKSPACE}`만 작업 경로로 치환한다. 셸 문자열로 합성하지 않는다.

도구는 코딩 도우미의 명시적 동적 도구 목록에만 노출한다. 매 호출마다 도구·명령·인자를 보여주고 사용자가 이번 실행을 승인해야 실행한다. Codex `command/exec`를 해당 작업 폴더에 쓰기 허용된 `wpl` 프로필로 실행하며, 네트워크는 비활성이다. 30초·1MiB 제한을 적용하고 결과·실제 exitCode를 기록한다. 추가 역할 권한을 자동 부여하지 않는다.

활성 변경·해제는 `profile_changed` 조건으로 남긴다. 추론 중 설정 변경과 시험 모드의 변경을 금지한다. 도구 목록 hash가 바뀌면 새 코딩 대화를 만들고 최근 공개 대화·선택 공유·메모로 맥락을 복구한다. 기존 호스트 MCP 설정은 별도로 비활성화한다.

`GET/POST /imports`, `PUT/DELETE /imports/:id`. 삭제·해제 후에는 도구 호출을 거절한다. 연결 해제는 사용자 원본 파일을 삭제하지 않는다.
