# 연습 비교

두 완료 평가의 원래 평가 ID와 버전을 보존한다. 과제 버전, rubricVersion, 모델, 수행 모드, 실연결/재생, 사전 조건 코드의 정렬 집합을 비교한다. 조건이 하나라도 다르면 차이를 명시하고 점수 차이를 계산하지 않는다. 같은 조건이어도 총점에 null이 있으면 우열이나 차이를 생성하지 않는다.

목록에서 두 연습을 고르면 최신 완료 평가를 사용한다. 평가 리포트에서는 각 버전을 따로 조회할 수 있다. 비교 JSON은 양쪽 원래 판정·근거 ID와 comparable/reasons/scoreDifference를 포함한다. 비교는 평가를 수정하지 않는다.

`GET /comparison?ids=<evaluation1>,<evaluation2>`, `GET /comparison/export?ids=...`. 최대 두 평가만 허용한다. 원시 점수의 동등한 조건 비교는 교육적 참고이며 공식 평가 동등성을 보장하지 않는다.
