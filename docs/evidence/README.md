# 공개 검증 요약

2026-10-30 기준, macOS Apple Silicon / Node.js 24.14.0 / pnpm 12.9.1에서 확인했습니다.

- 단위·통합 검사 60개 통과. 인증·요청 계약, 작업 복구, 제출 불변성, 평가 정책, 과제별 허용 모델을 포함합니다.
- 프로덕션 빌드와 TypeScript 검사 통과. 큰 프런트엔드 번들에 관한 빌드 경고는 남아 있습니다.
- 개발 과정에서 고객 응대·장비 예약 두 과제의 실제 AI 구현·검증·채점 흐름을 실행했습니다.
- 실제 모델 목록 조회와 Sol 6.1 세션 응답을 확인했습니다. 브라우저에서 허용 모델 3개 저장, 선택지 제한, Terra 5.6 응시 생성, 새로고침과 760px 화면을 확인했습니다.

개인 대화, 원시 런타임 이벤트, 로컬 경로, 계정별 세션 ID, 응시 리포트와 제출 산출물은 이 공개 저장소에 포함하지 않습니다. 이 문서는 확인한 범위를 요약하며 원시 근거를 대신하는 자동 검증 증명서가 아닙니다. `pnpm test`와 `pnpm build`로 코드 검사를 재현할 수 있습니다.

`pnpm test:live`는 로그인된 Codex 계정과 Docker가 필요하며 모델 이용량을 사용합니다. 실행하면 이 폴더에 로컬 결과가 생성될 수 있지만 Git에서는 제외됩니다. Linux·Windows 전체 흐름, 모든 모델별 채점 일관성과 실제 채용 평가 신뢰도는 검증하지 않았습니다.

## 0.3.0 — 에이전트 설치·문제 생성·다크모드

- 실제 `node tools/setup.mjs`로 의존성, Chromium, 빌드, 기존 앱과 다른 빈 포트의 서버 시작, 실제 Codex 연결·쓰기 경계·중단·복원까지 확인했습니다.
- CLI를 통해 Sol 6.1로 새 동아리 행사 신청 문제를 실제 생성·검사·등록했습니다. 앱에서도 별도의 간식 요청 문제를 생성했고 생성 도중 새로고침 후 완료 결과가 복원됐습니다.
- 외부 에이전트가 작성한 JSON의 CLI 검사·등록과 재시작 후 문제 보존을 확인했습니다.
- 다크모드 선택·새로고침 유지, 시스템 테마 변경, 코드 편집기 전환과 390px 화면의 가로 넘침 없음을 확인했습니다.
- 자동 검사에는 잘못된 참조·검사 정의·중복 버전 거절, 시험 중 제작 제한, 모델 오류, 취소와 완료의 경합, 실제 브라우저 단계 성공/실패가 포함됩니다. 생성 실패와 취소 테스트는 모의 모델을 사용하며 실제 AI 성공의 근거로 삼지 않습니다.
- 생성한 문제의 교육 품질·난이도와 모든 가능한 구현의 공정성까지 검증한 것은 아닙니다. 새 문제의 채점에 사용할 화면 검사는 공개된 test ID·문구 계약에 따릅니다.

테마 회귀 검사는 `WPL_BROWSER_SCRIPT=tests/e2e/theme-flow.mjs pnpm test:e2e`로 실행합니다. 서로 다른 탭의 테마 변경·시스템 설정·편집기 테마·390px 화면을 확인합니다. 초기 다중 탭 저장 경합은 수정 후 재검증했습니다.
