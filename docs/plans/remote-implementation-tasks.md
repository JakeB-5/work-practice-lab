# 원격 후속 구현 계획

단명 VM 실행 계층을 기준으로 분리한 후속 계획이며 아직 배포한 기능이 아니다.

| ID | 구현 산출물 | 선행 | 완료 검증 |
|---|---|---|---|
| R01 | 공급자·지역·비용·격리 설계 결정과 위협 모델 | 없음 | 요구별 책임·예산·운영자 검토 |
| R02 | OIDC 로그인·조직·역할·세션 서비스 | R01 | 탈퇴·만료·CSRF·교차 조직 테스트 |
| R03 | tenantId 데이터 이관·DB 정책 | R02 | 모든 ID 교체 공격과 삭제 제약 |
| R04 | 서명된 과제·제출 객체 저장 | R03 | 불변 digest·권한·만료 URL 검사 |
| R05 | 단명 VM 생성·lease·회수 관리자 | R01 | 시작 실패·호스트 장애·중복 lease 회수 |
| R06 | 공개 자료 주입·사전 준비·네트워크 정책 | R04,R05 | 비공개·다른 VM·메타데이터 서비스 접근 거절 |
| R07 | 모델 프록시·역할 도구 제한·단기 자격 | R02,R06 | 스코프·기한·철회·로그 비밀 검사 |
| R08 | 원격 PTY·프리뷰 별도 사이트·단기 티켓 | R02,R05 | 티켓 재사용·교차 사이트 제어 거절 |
| R09 | 제출 정지·복사·manifest commit·복구 | R04,R05,R08 | lease 변경·동시 쓰기·중복 제출 |
| R10 | 평가 작업 큐·근거 검증·재평가 버전 | R07,R09 | 실제 실행과 모델 주장 구분·유효하지 않은 근거 거절 |
| R11 | 비용·할당량·보존·삭제 job | R03,R05,R07 | 한도 초과·중단·파일/볼륨 잔존 검사 |
| R12 | 운영 관측·복구 훈련·백업 복원 | R09,R10,R11 | 장애 복구 목표와 삭제 감사 증거 |
| R13 | 제한된 조직 파일럿·접근성·부하 | R12 | 사용자 여정·격리·가용성·예산 승인 |

R01에서 공급자가 바뀌면 VM 이미지·네트워크·스토리지 작업을 재산정한다. 현재 로컬용 검증 결과만으로 R06/R08의 격리를 통과했다고 처리하지 않는다.
